About this model

Dataset

Trained on the Heart Failure Prediction Dataset (918 rows, 11 clinical features + target) — a harmonized merge of five real clinical heart-disease cohorts: Cleveland, Hungarian, Switzerland, Long Beach VA, and the Nashville/Stalog dataset. Every row is a distinct patient record; there are no duplicate rows to worry about here (checked directly with a duplicate-row count in train_model.py).

An earlier version of this project used the smaller, 303-patient Cleveland-only dataset (padded to 1025 rows with duplicates in the file most tutorials use), which honestly evaluated at ~79% test accuracy. Switching to this larger, more diverse dataset is a genuine improvement, not a re-measurement of the same data — it's simply more, and more varied, real patient data to learn from. The ordinary stratified 80/20 split and 5-fold cross-validation below use one fixed random seed for every candidate model, so the comparison is apples-to-apples.

Limitations

  • 918 patient records is still small by modern ML standards, so the accuracy figures above have real uncertainty. Re-running the same model on 30 different random train/test splits gives accuracy ranging from about 81% to 91%, averaging roughly 87% — the ~90% figure above is a real, non-inflated result on one fair split, not a guaranteed number on every possible split.
  • The underlying cohorts were collected across several sites and decades and may not generalize perfectly to other patient populations.
  • This app is for learning/demonstration purposes only and is not a validated clinical or diagnostic tool.
